# pfc-shell

The public, data-free front end of [Post Frontal Cortex](https://github.com/sugawolfdrew/PFC) —
a personal second brain: a private markdown wiki maintained by Claude Cowork sessions,
browsed through a faithful Windows 98 interface ([98.css](https://github.com/jdan/98.css)).

This shell contains **no personal data**. It authenticates with a fine-grained GitHub
token (stored only in your browser) and reads the private wiki repo client-side.
Try it with sample data: add `?demo=1`.

Fork it, point `CFG` at your own repo, and you have your own Cortex.
